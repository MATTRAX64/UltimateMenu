## Français

⏱️ **V1.4 — Ouverture Anticipée** ⏱️

Ce projet n'est pas affilié à Another Axiom ni à Gorilla Tag.

**C'est gratuit maintenant !**

### Interface

Le mod menu est organisé en 3 pages :
- **Accueil** : personnalisation de l'interface et réglages généraux.
- **Mods** : liste de tous les mods, active ou désactive chacun d'eux individuellement (un mod désactivé n'a plus aucun effet en jeu).
- **Page de mod** : en sélectionnant un mod, tu accèdes à ses propres paramètres spécifiques.

### Nouveautés V1.4
- Nouvelle interface style "Round"
- Simplification des mods
- Import de tous les fichiers directement dans le dossier du mod
- Ajout de sons dans l'interface

### Liste des mods

- **GorillaCamera** — Contrôleur de caméra pour des animations en boucle, durée personnalisable, modes Linéaire / Bézier...
- **GorillaDiscord** — Affiche simplement ton activité sur Discord.
- **GorillaFaces** — Anime la bouche en fonction de la parole, image par image.
- **GorillaMiror** — Améliore la qualité du miroir dans City.
- **GorillaMocaps** — Enregistre les mouvements en jeu pour des animations Blender. Caméra incluse, compatible Blender 4/5, à retrouver dans le dossier mocap.
- **GorillaNames** — Enregistre les pseudos en fonction du skin (10 actuellement en jeu, donc 10 pseudos différents), se met à jour correctement en rejoignant.
- **GorillaRooms** — Rejoins tes rooms, ajoute-les en favori, sélection aléatoire (pratique pour les lives).
- **GorillaShaders** — Shader visuel simple (à améliorer).
- **GorillaSpawners** — Fais apparaître des objets 3D en jeu et prends-les en main, visible uniquement sur ton ordinateur (local).
- **GorillaStreams** — Affiche ton code / le nombre de joueurs dans un coin pour le stream, exportable aussi en simple fichier texte dans le dossier.
- **GorillaTrackings** — Ajoute des possibilités de body tracking (comme le fan game), rend le mouvement plus lent/rapide, déplace le corps de façon originale, ou utilise un vrai tracker.
- **GorillaVoices** — Parle avec tes amis proches sans entendre les autres autour de toi, ou réduis leur volume.
- **GorillaWeather** — Change la météo (fonctionne, mais difficilement).

**Mods annexes / infos :**
- GorillaVoices Patch
- GorillaInterface — gère les mods en jeu
- GorillaNameTags — affiche le pseudo et la plateforme des joueurs

### Interface

The mod menu is organized into 3 pages:

### Mod list

- **GorillaCamera** — Camera controller for looping animations, custom duration, Linear / Bézier modes...

- **GorillaFaces** — Animates the mouth based on speech, frame by frame.
- **GorillaMiror** — Improves mirror quality in City.
- **GorillaMocaps** — Records in-game movement for Blender animations. Camera included, compatible with Blender 4/5, found in the mocap folder.
- **GorillaNames** — Records nicknames based on skin (10 currently in-game, so 10 different nicknames), updates correctly when rejoining.
- **GorillaRooms** — Join your rooms, favorite them, random selection (handy for streams).

- **GorillaStreams** — Shows your code / player count in a corner for streaming, also exportable as a simple text file in the folder.
- **GorillaTrackings** — Adds more body tracking options (like the fan game), makes movement slower/faster, moves the body in unusual ways, or uses a real tracker.
- **GorillaVoices** — Talk with close friends without hearing others around you, or lower their volume.
- **GorillaWeather** — Change the weather (works, but with difficulty).

**Additional mods / info:**
- GorillaVoices Patch
- GorillaInterface — manages mods in-game

## 日本語

⏱️ **V1.4 — アーリーアクセス** ⏱️

本プロジェクトは Another Axiom および Gorilla Tag とは一切関係ありません。

**今は無料です！**

### インターフェース

Mod メニューは3つのページで構成されています：
- **ホーム**：インターフェースのカスタマイズと全般設定。
- **Mods**：すべての mod の一覧。各 mod を個別に有効/無効にできます（無効化した mod はゲーム内で効果がなくなります）。
- **Mod ページ**：mod を選択すると、その mod 専用の設定にアクセスできます。

### V1.4 の新機能
- 新しい「Round」スタイルのインターフェース
- mod の簡略化
- すべてのファイルを mod フォルダに直接インポート可能
- インターフェースに音を追加

### Mod 一覧

- **GorillaCamera** — ループアニメーション用カメラコントローラー。時間指定可能、Linear／Bézier などのモード。
- **GorillaDiscord** — Discord のアクティビティをシンプルに表示。
- **GorillaFaces** — 発話に合わせて口を1コマずつアニメーション。
- **GorillaMiror** — City の鏡の画質を向上。
- **GorillaMocaps** — ゲーム内の動きを記録し、Blender アニメーションに使用可能。カメラ同梱、Blender 4/5対応、mocap フォルダ内にあります。
- **GorillaNames** — スキンに応じてニックネームを記録（現在ゲーム内に10種類、つまり10種類の異なるニックネーム）、再参加時に正しく更新されます。
- **GorillaRooms** — ルームに参加し、お気に入り登録、ランダム選択（配信に便利）。
- **GorillaShaders** — シンプルなビジュアルシェーダー（改善予定）。
- **GorillaSpawners** — ゲーム内に3Dオブジェクトを出現させ、手に持つことができます。自分のPCでのみ表示（ローカル）。
- **GorillaStreams** — 配信用にコードやプレイヤー数を画面の隅に表示、フォルダ内のシンプルなテキストファイルとしても出力可能。
- **GorillaTrackings** — ファンゲームのような body tracking の追加機能。動きを遅く/速くしたり、体を独特な形で動かしたり、実際のトラッカーを使用可能。
- **GorillaVoices** — 周りの音を聞かずに親しい友達とだけ話せる、または音量を下げられる mod。
- **GorillaWeather** — 天気を変更（動作しますが不安定です）。

**追加 mod／情報：**
- GorillaVoices Patch
- GorillaInterface — ゲーム内での mod 管理
- GorillaNameTags — プレイヤーのニックネームとプラットフォームを表示
